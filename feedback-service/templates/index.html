How ratings work

One rating per GitHub user ID per repository. Ratings and reviews are independent. The score is the simple mean of eligible ratings.

GitHub accounts younger than 30 days wait until eligible. GitHub sign-in verifies the account, but cannot tell whether multiple accounts belong to one person. The service operator controls the application and stored data.
