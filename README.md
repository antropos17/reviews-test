<details>
<summary>How ratings work</summary>

One vote per GitHub user ID. A new submission replaces the previous one; rating text is optional.

Accounts must be at least 30 days old. Newer or unverified accounts wait until eligible; approval labels do not bypass this rule. Bots and pull requests are excluded.

The score is the simple average of eligible ratings. Hidden, blocked, invalid, and pending entries are excluded; the owner can hide reviews and block account IDs.

This is a self-hosted system: the repository owner can change its code and settings. It cannot identify multiple accounts belonging to the same person.

[Source and settings](https://github.com/antropos17/reviews-test/tree/main/.github/repo-reviews) · [Rating code](https://github.com/antropos17/reviews-test/blob/main/scripts/repo_reviews.py) · [Data and history](https://github.com/antropos17/reviews-test/commits/reviews/)

Updates follow GitHub Actions and may be delayed.
